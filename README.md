# 立ち呑み地形図（Tachinomi Atlas）

東京都・埼玉県の立ち呑み屋を3D地図上で探し、比較し、記録するための個人用Webアプリです。
仕様は [docs/SPEC.md](docs/SPEC.md)、開発計画と進捗は [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) を参照してください。

> **現在の状態：Phase 4（個人記録）まで実装済み**
> 3D地図、店舗の登録・編集・削除・検索、酒場密度・分布の表示、市区町村別・駅周辺の集計に加え、訪問記録・お気に入り・行きたい店・再訪したい店の記録、訪問履歴、JSON でのバックアップと復元が動作します。
> はしご酒プランナー（Phase 5）は**未実装**です。
>
> **初期店舗データは OpenStreetMap 由来の22件（東京都19・埼玉県3）です。** うち **3件は運営会社の公式サイトで住所・営業時間を確認済み**、残り19件は「未確認」です。
> 未確認の店舗は名称と位置（2件は住所も）のみで、営業状況・営業時間・価格は確認できていません。詳細は [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md) を参照してください。
> 密度や集計の数値は**登録済みの店舗の件数**で、実際の店舗数や街の酒場の多さを示すものではありません。

操作方法の詳細は [docs/USER_GUIDE.md](docs/USER_GUIDE.md) を参照してください。

## 必要なもの

- Windows 10/11（macOS・Linux でも動作します）
- [Node.js](https://nodejs.org/ja) **22.12 以上**（LTS版を推奨）
- WebGL が使えるブラウザ（Chrome / Edge / Firefox の最新版）
- インターネット接続（地図タイルの取得に使用）

## 起動方法（Windows）

PowerShell またはコマンドプロンプトで、このフォルダーに移動して実行します。

```powershell
npm install
npm run dev
```

表示された URL（通常は http://localhost:5173/ ）をブラウザで開きます。停止するときは `Ctrl + C` を押します。

本番用にビルドして確認する場合：

```powershell
npm run build
npm run preview
```

## 設定

- **APIキーは不要です。** 地図タイルには OpenFreeMap（登録・キー不要）を使用しています。
- 地図スタイルは画面上部の「地図スタイル」から「ダーク／標準／淡色」を切り替えられます。
- 環境変数による設定は現時点ではありません。

## 地図の操作

| 操作                 | 方法                                                                      |
| -------------------- | ------------------------------------------------------------------------- |
| 移動                 | 左ドラッグ、矢印キー                                                      |
| 拡大・縮小           | マウスホイール、ダブルクリック、右上の ＋／− ボタン、`+` `-` キー         |
| 回転・傾き           | 右ドラッグ、または `Ctrl` ＋ 左ドラッグ。右上のコンパスをドラッグしても可 |
| 北を上に戻す         | 右上のコンパスをクリック、または左パネル「北を上にする」                  |
| 初期表示に戻る       | 左パネル「初期表示に戻る」                                                |
| 東京・埼玉全域を表示 | 左パネル「東京・埼玉 全域」、または上部「地域」で選択                     |
| 地域へ移動           | 上部「地域」で 23区／多摩／埼玉南部／埼玉北部・秩父 を選択                |
| 2D／3D切り替え       | 左パネル「2D表示」「3D表示」（3D表示は建物が見えるズームまで寄ります）    |
| 3D建物の表示切り替え | 左パネル「3D建物」（ズーム13以上で立体表示）                              |
| 全画面表示           | 右上の全画面ボタン                                                        |
| パネルを閉じる       | 左パネル上部「◀ 閉じる」                                                  |

左パネルは「店舗を探す」（検索条件と結果一覧）と「地図の表示」（レイヤーと地図操作）のタブに分かれています。

## 店舗の操作

| 操作               | 方法                                                                    |
| ------------------ | ----------------------------------------------------------------------- |
| 店舗を探す         | 上部の検索欄（店名・住所）、左パネル「絞り込み条件」                    |
| 条件の解除         | 適用中の条件のボタン（✕）、または「条件をすべて解除」                   |
| 店舗を選ぶ         | 地図のマーカー、または左パネルの一覧をクリック                          |
| まとめ表示を広げる | オレンジの丸（複数店舗のまとまり）をクリック                            |
| 店舗を追加         | 上部「＋ 店舗を追加」。位置は「地図をクリックして位置を選択」でも入力可 |
| 編集・削除         | 店舗詳細パネルの「編集」「削除」                                        |
| 駅から探す         | 絞り込み条件「駅を起点に探す」で駅と距離（300/500/800m）を選ぶ          |

## 密度・比較

| 操作                     | 方法                                                                                                                        |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 表示モードの切り替え     | 左パネル「地図の表示」→「表示モード」（店舗マーカー／密度（ヒートマップ）／密度（3D柱）／ジャンル別の分布／予算帯別の分布） |
| 凡例                     | 地図の右下に、選んだ表示モードの凡例と対象件数を表示（「隠す」で折りたたみ）                                                |
| 駅の表示                 | 左パネル「地図の表示」→「駅」（ズーム12以上で表示）                                                                         |
| 市区町村別・駅周辺の集計 | 左パネル「比較・集計」。駅名を押すとその駅を起点に絞り込み                                                                  |
| 調査済みエリア           | 左パネル「比較・集計」→「＋ 調査済みエリアを追加」。密度表示で「調査済み・0件」と「データなし」を区別                       |

## 地図が表示されないとき

- 画面上部に**原因と対処**が表示されます。インターネット接続を確認し「再読み込み」を押してください。
- 地図サービスに接続できない場合は、背景のみの「簡易表示」に切り替わります（地図操作は可能）。
- 「WebGL を表示できません」と出る場合は、ブラウザ設定でハードウェア アクセラレーションを有効にしてください。

## データの保存場所・バックアップ

| データ                           | 保存場所                                                                                       |
| -------------------------------- | ---------------------------------------------------------------------------------------------- |
| 初期店舗データ                   | `src/data/shops.json`（出典は `sources.json`、駅は `stations.json`）。アプリに同梱             |
| 画面から追加・編集した店舗と出典 | ブラウザ内の IndexedDB（データベース名 `tachinomi-atlas`）                                     |
| 画面から削除した初期データの店舗 | 同上（削除した記録を保存し、再表示しない）                                                     |
| 調査済みエリア                   | 同上                                                                                           |
| 訪問記録・お気に入り等           | 同上（店舗データとは別のストアに保存）                                                         |
| 最終バックアップ日時             | 同上                                                                                           |
| 駅データ                         | `src/data/stations.json`（国土数値情報から `scripts/build-stations.mjs` で生成）。アプリに同梱 |

- 同じIDの店舗は、画面で編集した内容が初期データより優先されます。初期データを更新しても編集内容は消えません。
- IndexedDB のデータは、ブラウザの「閲覧データの削除」やプライベートウィンドウの終了で失われます。また、ブラウザやPCをまたいで共有されません。
- **バックアップ**：画面上部の「データ管理」→「全データのバックアップを書き出す」で JSON ファイルに保存します（ブラウザのダウンロードフォルダに保存されます）。最終バックアップから30日以上たつと、データ管理画面で書き出しをおすすめします。
- **復元**：「データ管理」→「読み込み（復元）」でファイルを選ぶと、内容を検証して件数と注意点を表示します。「統合する」（同じIDは上書き）か「置き換える」（今のデータを消してから読み込む）を選び、確認後に読み込みます。検証で問題があるファイルは読み込みません。保存中に失敗した場合も、データは変更されません。
- バックアップには訪問の感想など個人的なメモが含まれます。共有する場合は内容に注意してください。
- 個人記録は外部に送信しません。写真は「ファイル名・保存場所のメモ」として記録するだけで、画像そのものは保存・アップロードしません。

## 開発者向けコマンド

| コマンド            | 内容                                               |
| ------------------- | -------------------------------------------------- |
| `npm run dev`       | 開発サーバーを起動                                 |
| `npm run typecheck` | TypeScript の型チェック                            |
| `npm test`          | 単体・コンポーネントテスト（Vitest、外部通信なし） |
| `npm run test:e2e`  | ブラウザでのE2Eテスト（Playwright、外部通信なし）  |
| `npm run build`     | 型チェック＋本番ビルド（`dist/`）                  |
| `npm run check`     | 型チェック・単体テスト・ビルドをまとめて実行       |

E2E テストを初めて実行する前に、テスト用ブラウザを一度だけ取得してください。

```powershell
npx playwright install chromium
```

E2E テストは地図スタイルをテスト用の固定データに差し替えるため、外部ネットワークなしで動きます。
実際の OpenFreeMap に接続して確認するテストは、環境変数を指定したときだけ実行されます（PowerShell の例）：

```powershell
$env:E2E_EXTERNAL=1; npm run test:e2e
```

本番ビルドに対して E2E テストを行う場合は `$env:E2E_USE_PREVIEW=1` を指定します。

## 既知の制約

- 地図タイルは OpenFreeMap の公開サービスに依存します。SLA はなく、停止や仕様変更の可能性があります。
- 「ダーク」「淡色」スタイルは OpenMapTiles 由来の旧スタイルで、上流の更新は止まっています。表示に問題がある場合は「標準」を選んでください。
- 3D建物の高さは OpenStreetMap に登録された値（無い場合は推定値）に基づくため、実際と異なる場合があります。
- 島しょ部（伊豆諸島・小笠原諸島）は地域切り替えの対象外です。
- 駅からの距離はすべて直線距離で、徒歩の道のりではありません。
- 密度・集計は登録済みの店舗だけに基づきます。調査済みエリアの外で店舗が表示されなくても「店が少ない」とは言えません。
- 「営業中」の判定は登録された営業時間（日本時間）に基づく参考情報です。臨時休業・祝日は反映されません。
- 店名ラベルは、地図スタイルのフォント配信を使うため、地図サービスに接続できない簡易表示では表示されません（マーカーは表示されます）。
- スマートフォン表示は対象外です（PC のブラウザ幅 960px 以上を想定）。
