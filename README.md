# 立ち呑み地形図（Tachinomi Atlas）

東京都・埼玉県の立ち呑み屋を3D地図上で探し、比較し、記録するための個人用Webアプリです。
仕様は [docs/SPEC.md](docs/SPEC.md)、開発計画と進捗は [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) を参照してください。

> **現在の状態：Phase 1（地図の基礎）まで実装済み**
> 3D地図の表示・操作・エラー表示のみ動作します。店舗の表示・検索、密度表示、訪問記録、はしご酒プランナーは**未実装**です（Phase 2 以降）。

## 必要なもの

- Windows 10/11（macOS・Linux でも動作します）
- [Node.js](https://nodejs.org/ja) **22.12 以上**（LTS版を推奨）
- WebGL が使えるブラウザ（Chrome / Edge / Firefox の最新版）
- インターネット接続（地図タイルの取得に使用）

## 起動方法（Windows）

PowerShell またはコマンドプロンプトで、このフォルダーに移動して実行します。

```powershell
npm install
npm run dev
```

表示された URL（通常は http://localhost:5173/ ）をブラウザで開きます。停止するときは `Ctrl + C` を押します。

本番用にビルドして確認する場合：

```powershell
npm run build
npm run preview
```

## 設定

- **APIキーは不要です。** 地図タイルには OpenFreeMap（登録・キー不要）を使用しています。
- 地図スタイルは画面上部の「地図スタイル」から「ダーク／標準／淡色」を切り替えられます。
- 環境変数による設定は現時点ではありません。

## 地図の操作

| 操作 | 方法 |
|---|---|
| 移動 | 左ドラッグ、矢印キー |
| 拡大・縮小 | マウスホイール、ダブルクリック、右上の ＋／− ボタン、`+` `-` キー |
| 回転・傾き | 右ドラッグ、または `Ctrl` ＋ 左ドラッグ。右上のコンパスをドラッグしても可 |
| 北を上に戻す | 右上のコンパスをクリック、または左パネル「北を上にする」 |
| 初期表示に戻る | 左パネル「初期表示に戻る」 |
| 東京・埼玉全域を表示 | 左パネル「東京・埼玉 全域」、または上部「地域」で選択 |
| 地域へ移動 | 上部「地域」で 23区／多摩／埼玉南部／埼玉北部・秩父 を選択 |
| 2D／3D切り替え | 左パネル「2D表示」「3D表示」（3D表示は建物が見えるズームまで寄ります） |
| 3D建物の表示切り替え | 左パネル「3D建物」（ズーム13以上で立体表示） |
| 全画面表示 | 右上の全画面ボタン |
| パネルを閉じる | 左パネル上部「◀ 閉じる」 |

## 地図が表示されないとき

- 画面上部に**原因と対処**が表示されます。インターネット接続を確認し「再読み込み」を押してください。
- 地図サービスに接続できない場合は、背景のみの「簡易表示」に切り替わります（地図操作は可能）。
- 「WebGL を表示できません」と出る場合は、ブラウザ設定でハードウェア アクセラレーションを有効にしてください。

## データの保存場所・バックアップ

Phase 1 時点では、アプリは個人データを保存しません。
店舗データ（JSON）と個人記録（ブラウザの IndexedDB）の保存、JSON によるバックアップは Phase 2・4 で実装予定です。

## 開発者向けコマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバーを起動 |
| `npm run typecheck` | TypeScript の型チェック |
| `npm test` | 単体・コンポーネントテスト（Vitest、外部通信なし） |
| `npm run test:e2e` | ブラウザでのE2Eテスト（Playwright、外部通信なし） |
| `npm run build` | 型チェック＋本番ビルド（`dist/`） |
| `npm run check` | 型チェック・単体テスト・ビルドをまとめて実行 |

E2E テストを初めて実行する前に、テスト用ブラウザを一度だけ取得してください。

```powershell
npx playwright install chromium
```

E2E テストは地図スタイルをテスト用の固定データに差し替えるため、外部ネットワークなしで動きます。
実際の OpenFreeMap に接続して確認するテストは、環境変数を指定したときだけ実行されます（PowerShell の例）：

```powershell
$env:E2E_EXTERNAL=1; npm run test:e2e
```

本番ビルドに対して E2E テストを行う場合は `$env:E2E_USE_PREVIEW=1` を指定します。

## 既知の制約

- 地図タイルは OpenFreeMap の公開サービスに依存します。SLA はなく、停止や仕様変更の可能性があります。
- 「ダーク」「淡色」スタイルは OpenMapTiles 由来の旧スタイルで、上流の更新は止まっています。表示に問題がある場合は「標準」を選んでください。
- 3D建物の高さは OpenStreetMap に登録された値（無い場合は推定値）に基づくため、実際と異なる場合があります。
- 島しょ部（伊豆諸島・小笠原諸島）は地域切り替えの対象外です。
- スマートフォン表示は対象外です（PC のブラウザ幅 960px 以上を想定）。
