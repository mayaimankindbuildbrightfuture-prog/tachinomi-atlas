# データソースと利用条件

本アプリが利用する外部データ・サービスと、その利用条件の確認記録です。
利用条件は変わる可能性があるため、データを追加・公開する前に必ず最新の規約を確認してください。

## 地図タイル：OpenFreeMap

| 項目          | 内容                                                                                                                                                                                                                  |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 提供元        | OpenFreeMap（https://openfreemap.org/）                                                                                                                                                                               |
| 使用URL       | `https://tiles.openfreemap.org/styles/{dark,liberty,positron}`                                                                                                                                                        |
| データ        | OpenStreetMap（ODbL）を OpenMapTiles スキーマでタイル化したもの                                                                                                                                                       |
| APIキー・登録 | 不要                                                                                                                                                                                                                  |
| 利用制限      | 公式サイトの記載では、表示回数・リクエスト数の上限なし                                                                                                                                                                |
| 帰属表示      | **必須**。「OpenFreeMap © OpenMapTiles Data from OpenStreetMap」。MapLibre の帰属表示コントロールがスタイル内の表記を自動表示する（本アプリは `AttributionControl` を常時展開表示）。画面下部のステータスバーにも併記 |
| 保証          | SLA なし。提供内容は予告なく変更・終了される可能性がある                                                                                                                                                              |
| 確認日        | 2026-10-29（Web検索結果による。開発用クラウド環境からは openfreemap.org へ直接接続できなかったため、公式ページの原文は未確認）                                                                                        |

### 停止時の扱い

- スタイルが取得できない場合は、外部通信を行わない背景のみの簡易スタイルに切り替え、原因と対処を表示する。
- タイルの一部が取得できない場合は、失敗件数を表示する（自前の無限再試行はしない）。

## 地名表記

OpenMapTiles の `name:ja` 属性を優先し、無い場合は `name` を表示する。

## 店舗データ

### 登録の方針

- 実在店舗の情報は、出典（公式サイト・オープンデータ・現地確認など）と確認日を必ず記録する。
- 出典の利用規約・ライセンス・出典表示義務を確認し、この文書に追記する。
- 確認できない情報は登録しない（不明な項目は `null`・空配列・`"unknown"` のまま）。
- 動作確認用のデータを入れる場合は、「デモデータ」であることが分かるIDと名称を付ける。
- ウェブサイトの無断スクレイピングや規約に反する大量取得は行わない。

### 現在の登録状況（2026-10-29）

**初期データは OpenStreetMap 由来の 22 件（東京都 19、埼玉県 3）。うち 3 件は公式サイトで確認済み（`verified`）、19 件は未確認（`unverified`）。**

#### 取得方法

1. Nominatim（OpenStreetMap の検索API）で、店名に「立ち飲み」「立飲み」「立ち呑み」「立呑み」「立呑」「立飲」「角打ち」「角打」を含む地物を、東京都・埼玉県周辺の範囲に限定して検索（計8回、1回ごとに間隔を空け、連絡先入りの User-Agent を付けて実行）。
2. 結果から、種別が飲食店・酒店（`amenity=bar/pub/restaurant`、`shop=alcohol`）で、所在が東京都（JP-13）・埼玉県（JP-11）のものだけを残した（22件）。
3. 各地物の全タグ・版・最終編集日を OpenStreetMap API（`www.openstreetmap.org/api/0.6/node/{id}`）で取得（22回）。
   overpass-api.de は開発環境からの接続がサーバー側で切断されたため使っていない。

#### 登録した内容と、登録しなかった内容

| 項目                                         | 扱い                                                                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 店名                                         | OSM の `name`（全角スペースは半角に統一）                                                                                                  |
| 緯度・経度                                   | OSM の座標                                                                                                                                 |
| 住所                                         | OSM に `addr:*` タグがある2件のみ。他は `null`（Nominatim が境界データから算出した地域名は住所ではないため、メモに「所在地域」として記載） |
| 都道府県・市区町村                           | Nominatim が OSM の行政界から算出した値                                                                                                    |
| 料理ジャンル                                 | 店名に「角打」を含む店、または酒屋（`shop=alcohol`）で店名に「立飲み」を含む店のみ「角打ち」。他は未分類                                   |
| 立ち呑み専業・座席                           | 店名は立ち飲みを示すが、専業か・座席があるかは不明なため `null`                                                                            |
| 営業時間・価格・予算帯・酒の種類・公式サイト | 該当タグがある店はなく、すべて未登録                                                                                                       |
| 出典                                         | 店ごとに OSM 地物ページへのリンク、参照日 2026-10-29、版・最終編集日、OSM 上の `check_date`・`source` タグ                                 |

#### 「未確認」にしている理由

OpenStreetMap は利用者が編集する地図で、地物の最終編集日は 2009〜2026 年とばらつきがある。
OSM に載っていることは「その時点で誰かが地図に記録した」ことを示すだけで、現在の営業は保証しない。
そのため、**出典はあるが内容は未確認**として登録し、`lastVerifiedAt` は付けていない。
「確認済み」にするには、公式サイトや現地確認など、現在の情報を確かめられる出典を追加する。

#### 注意が必要な店舗

- 最終編集が 2020 年以前で `check_date` もない店舗は、メモに「現在の営業は特に要確認」と記載。
- 「立ち飲み日高」は OSM 上に約140m離れて2地点ある。別の店舗か重複登録かは未確認のため、両方を登録しメモに記載。

#### 公式サイトでの確認（2026-10-29）

22 件すべてについて、Web 検索で公式サイト・公式SNSを探した。採用したのは、店舗または運営会社自身が公開しているページだけ。
食べログ・Retty・ぐるなび・ホットペッパー等のグルメサイトや紹介記事は、公式ではないため出典にしていない。

**確認できた店舗（3件、`verified`）**

| 店舗（OSM上の名称）                       | 公式の出典                                                                                       | 確認した内容                           |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------- |
| 立呑み晩杯屋 吉祥寺店（立呑み晩杯屋）     | [晩杯屋 公式サイト（株式会社アクティブソース）](https://active-source.co.jp/area/musashino-shi/) | 店名・住所・曜日別営業時間・電話番号   |
| 焼鳥日高 大宮一番街店（立ち飲み日高）     | [ハイデイ日高 公式 店舗情報](https://hidakaya.hiday.co.jp/hits/ja/shop/6/detail/266.html)        | 店名・住所・曜日別営業時間・特別営業日 |

**確認できなかった店舗（19件、`unverified` のまま）**

- 「立ち飲み いこい」（北区上中里）は、同名店の公式とみられる Instagram・X があるがログインが必要で内容を確認できず、またグルメサイト上の同名店の所在（赤羽）と OSM の位置（上中里）が一致しないため、未確認のまま。

### 候補となる出典と利用条件の論点

| 出典                                      | 用途                       | 確認が必要な点                                                                                                                                                                                 |
| ----------------------------------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 店舗の公式サイト・公式SNS                 | 店名・住所・営業時間・価格 | 各サイトの利用規約。事実情報の転記にとどめ、文章や写真は転載しない                                                                                                                             |
| OpenStreetMap（Overpass API / Nominatim） | 店舗の存在・座標・住所     | ODbL：出典表示「© OpenStreetMap contributors」が必要。抽出したデータベースを公開・配布する場合は同じライセンスでの提供（継承）が必要。Nominatim は利用規約上、1秒1リクエスト以下・大量取得禁止 |
| 国土数値情報（駅データ）                  | 駅の名称・座標・路線       | 利用規約（出典表示）。商用利用の可否はデータごとに確認                                                                                                                                         |
| 現地確認                                  | すべて                     | 確認日を記録する                                                                                                                                                                               |

### JSON の形式

`src/data/shops.json`

```json
{
  "schemaVersion": 1,
  "shops": [
    {
      "id": "tokyo-kita-xxxx",
      "name": "店名",
      "latitude": 35.0,
      "longitude": 139.0,
      "address": null,
      "prefecture": "東京都",
      "municipality": null,
      "stationIds": [],
      "categories": ["yakitori"],
      "drinkTags": [],
      "standingOnly": null,
      "hasSeating": null,
      "priceLevel": "unknown",
      "priceExamples": [],
      "openingHours": [],
      "officialUrl": null,
      "status": "verified",
      "sourceIds": ["src-xxxx"],
      "createdAt": "2026-10-29T00:00:00.000Z",
      "updatedAt": "2026-10-29T00:00:00.000Z",
      "lastVerifiedAt": "2026-10-29"
    }
  ]
}
```

- `categories` のキー：`yakitori` `nikomi` `oden` `seafood` `sake` `beer` `kakuuchi` `other`
- `status` が `verified` の場合、`sourceIds` 1件以上と `lastVerifiedAt` が必須（検証で弾かれる）。
- `src/data/sources.json` に `{ "schemaVersion": 1, "sources": [DataSource...] }`、`src/data/stations.json` に `{ "schemaVersion": 1, "stations": [Station...] }` を置く。
- 起動時に全件を検証し、不正なデータ・重複ID・存在しない出典や駅への参照は画面左下に一覧表示する（不正なデータは読み込まない）。
- `npm test` でも同梱データの検証を行う（`src/domain/dataset.test.ts`）。

## 駅データ：国土数値情報

| 項目       | 内容                                                                                                                                                       |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 提供元     | 国土交通省 国土数値情報ダウンロードサイト                                                                                                                  |
| 使用データ | 鉄道データ N02（令和6年度、[データ概要](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2024.html)）、行政区域データ N03（令和7年、東京都・埼玉県） |
| ライセンス | オープンデータ（CC BY 4.0）。いずれもデータ概要ページの「使用許諾条件」で確認（2026-10-29）                                                                |
| 出典表示   | 「国土数値情報（国土交通省）を加工して作成」。`src/data/LICENSE-DATA.md`、`sources.json`（`src-ksj-n02-2024`）に記載                                       |
| 件数       | 884駅（東京都 656、埼玉県 228。島しょ部を除く）                                                                                                            |

### 生成方法

1. 上記ページから `N02-24_GML.zip`、`N03-20250101_13_GML.zip`、`N03-20250101_11_GML.zip` をダウンロードして展開する。
2. 次のコマンドで `src/data/stations.json` を生成する。

```bash
node scripts/build-stations.mjs <N02-24_Station.geojson> <N03-20250101_13.geojson> <N03-20250101_11.geojson>
```

- 同じ駅グループコード（`N02_005g`）の駅を1駅にまとめ、路線を「事業者 路線名」の一覧にする（例：大宮は7路線）。
- 座標はグループ内の駅（ホームを表す線）の中点の平均。駅舎や出入口の位置ではない。
- 都道府県・市区町村は、座標を含む行政区域（N03）から判定。政令指定都市は「さいたま市大宮区」のように区まで付ける。
- 同じ名前でも駅グループが異なる駅（例：東京駅の京葉線ホーム）は別の駅として残す。画面では路線を併記して区別する。

### 使い方の制約

- 駅からの距離はすべて直線距離。徒歩の道のりや所要時間ではない。
- 店舗の「最寄り駅」（`stationIds`）は利用者が選んだもののみ。距離から自動で登録はしない。

## 調査済みエリア

利用者が「この範囲の立ち呑み屋は一通り調べた」と記録する範囲（中心・半径・調査日・調査対象）。ブラウザ内（IndexedDB）に保存する。
密度表示（3D柱）で、エリア内の店舗0件のマスを「調査済み・0件」として「データなし」と区別するために使う。
初期データとしての調査済みエリアは無い（同梱の店舗データは網羅的な調査ではないため）。

## 徒歩経路

調査日：2026-10-29（Web 検索による。開発環境から各サービスの規約ページを直接は開けていない）

| 候補                                             | 判断                     | 理由                                                                                                                                              |
| ------------------------------------------------ | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| openrouteservice（HeiGIT）                       | **任意で利用可能にした** | 無料の Standard プラン（API キー必要、経路検索1日2,000回・1分40回、経由地50まで）の条件が公開されている。利用者が自分でキーを設定した場合のみ使う |
| FOSSGIS 経路サーバー（routing.openstreetmap.de） | 使わない                 | 利用条件の原文（ドイツ語）を確認できず、リクエストがサーバーに記録されると説明されている                                                          |
| OSRM 公開デモ（router.project-osrm.org）         | 使わない                 | 情報源により徒歩プロファイルの有無が食い違い、デモ用途の位置付け                                                                                  |

### 実装方針

- 既定は外部通信なし。2地点間の**直線距離**と、それを分速80m（不動産の表示に関する公正競争規約の「徒歩1分＝80m」）で割った**概算**を表示し、画面上で「直線」「概算」と明示する。地図では点線で描き、徒歩経路と誤認させない。
- openrouteservice は、利用者が API キーを設定し「徒歩ルートを取得」を押したときだけ呼び出す。送るのはルート上の店舗・駅の座標のみ。応答は地点の並びごとに保持し、同じ並びで再要求しない。失敗時に自動再試行はしない。
- API キーはブラウザ内（IndexedDB の meta ストア）に保存し、ソースコード・リポジトリ・バックアップには含めない。
- 帰属表示「openrouteservice.org by HeiGIT／地図データ © OpenStreetMap contributors」を、取得した経路を表示するときと設定画面に表示する。
- **未確認事項**：開発環境から openrouteservice に接続できなかったため、実際のサービスでの動作は確認していない（応答形式は公開ドキュメントに基づき実装し、テストでは固定の応答で確認）。
