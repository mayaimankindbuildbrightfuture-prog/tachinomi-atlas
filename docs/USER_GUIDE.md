# 利用ガイド

立ち呑み地形図の操作方法です。起動方法は [README](../README.md) を参照してください。

> 対象：Phase 2 までの機能。密度表示・訪問記録・バックアップ・はしご酒プランナーは今後追加されます。

## 画面構成

| 位置 | 内容                                                                                                                     |
| ---- | ------------------------------------------------------------------------------------------------------------------------ |
| 上部 | アプリ名、店名・住所の検索欄（右端に結果件数）、「＋ 店舗を追加」、地域の移動、地図スタイル                              |
| 左   | 「店舗を探す」タブ（件数・適用中の条件・絞り込み条件・結果一覧）／「地図の表示」タブ（3D建物、視点操作、マーカーの見方） |
| 中央 | 3D地図                                                                                                                   |
| 右   | 選んだ店舗の詳細、または追加・編集フォーム（✕で閉じると地図が広がります）                                                |
| 下部 | 地図の状態（中心座標・ズーム・傾き・方位）と地図の出典                                                                   |

## 地図のマーカー

- 丸の中の一文字が料理ジャンルです。

  | 文字 | ジャンル         |
  | ---- | ---------------- |
  | 焼   | 焼きとん・焼き鳥 |
  | 煮   | 煮込み           |
  | お   | おでん           |
  | 魚   | 刺身・海鮮       |
  | 酒   | 日本酒           |
  | 麦   | ビール・ホッピー |
  | 角   | 角打ち           |
  | 他   | その他・未分類   |

- 複数のジャンルを持つ店舗は、最初に登録したジャンルで表示されます（全ジャンルは詳細パネルで確認できます）。
- オレンジの大きな丸は近くにある複数店舗のまとまりです。クリックすると拡大します。ズーム15程度まで寄ると個別に表示されます。
- 半透明のマーカーは「閉店の可能性あり」「閉店確認済み」の店舗です。
- 選択中の店舗は白い輪で囲まれます。
- 地図上の店舗は、現在の検索条件に合う店舗だけが表示されます。

## 店舗を探す

1. 上部の検索欄に店名や住所の一部を入力します（全角・半角、空白の違いは無視されます）。
2. 左パネルの「絞り込み条件」を開き、条件を選びます。条件はすべて同時に適用されます（AND）。同じ項目内で複数選んだ場合は、いずれかに当てはまる店舗が対象です。
3. 適用中の条件は件数の下にボタンで表示されます。押すとその条件だけ解除されます。

| 条件         | 注意                                                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 立ち呑み形式 | 形式が「未確認」の店舗は、形式を指定すると結果に含まれません                                                                                                       |
| 営業日時     | 登録された営業時間（日本時間）で判定します。営業時間が未確認の店舗は、「営業時間が未確認の店舗も含める」を選ばない限り含まれません。臨時休業・祝日は反映されません |
| 最寄り駅     | 駅データが未登録のため、現在は選べません                                                                                                                           |

## 店舗の詳細

- 分からない情報は「未確認」と表示されます。アプリが推測で補うことはありません。
- 「確認状況」が「未確認」の店舗には注意書きが表示されます。
- 価格例は品目ごとに確認日・出典を表示します。税・お通し・チャージが含まれない場合があります。
- 営業時間の下に、登録内容に基づく現在の営業状況（参考）を表示します。判定できない場合は「判定できません」と表示します。
- 公式サイトや出典のリンクは、リンク先のドメインを表示し、新しいタブで開きます。

## 店舗を追加・編集する

1. 上部「＋ 店舗を追加」、または詳細パネルの「編集」を押します。
2. **必須は店名・緯度・経度のみ**です。分からない項目は空欄や「未確認」のままにしてください。
3. 位置は次のどちらかで入力します。
   - 緯度・経度を直接入力（例：緯度 35.6812、経度 139.7671）
   - 「地図をクリックして位置を選択」を押し、地図上をクリック
     入力した位置には地図上に白いピンが表示されます。
4. 緯度と経度が逆の場合や、東京都・埼玉県の範囲外の場合は警告が表示されます。
5. 営業時間は曜日ごとに「未確認／営業／定休日」を選びます。深夜営業は閉店時刻を開店時刻より前（例：17:00〜02:00）にすると翌日にまたがる扱いになります。
6. 出典は「新しい出典を追加」から登録し、チェックを付けてその店舗に紐づけます。
7. 「確認済み」にするには、出典1件以上と最終確認日が必要です。
8. 同じ名前の店舗が150m以内にある場合は重複の可能性を表示します。別の店舗であれば「別の店舗として登録する」にチェックしてから保存します。

## 店舗を削除する

詳細パネルの「削除」を押し、確認画面で「削除する」を押します。取り消しはできません。
初期データの店舗を削除した場合は、削除した記録が保存され、次回以降も表示されません。

## データの保存とバックアップ

画面で追加・編集したデータはブラウザ内（IndexedDB）に保存され、ページを再読み込みしても残ります。
ただし、ブラウザの閲覧データを削除すると失われます。JSON でのバックアップ機能は今後追加予定です。

## うまく動かないとき

| 症状                                     | 対処                                                                                                           |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 地図が表示されない                       | 画面上部に原因と対処が表示されます。インターネット接続を確認し「再読み込み」を押してください                   |
| 「保存済みデータを読み込めませんでした」 | プライベートウィンドウでは保存できない場合があります。通常のウィンドウで開いてください                         |
| 「店舗データを保存できませんでした」     | ブラウザの空き容量や設定を確認してください。入力内容はフォームに残っています                                   |
| 「店舗データに確認が必要な点があります」 | 初期データ（JSON）に不正な値や存在しない出典・駅の参照があります。一覧の内容を確認して JSON を修正してください |
