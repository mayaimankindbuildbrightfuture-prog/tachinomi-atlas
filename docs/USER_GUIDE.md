# 利用ガイド

立ち呑み地形図の操作方法です。起動方法は [README](../README.md) を参照してください。

> 対象：v1.0（仕様書の Phase 1〜5）。

## 画面構成

| 位置       | 内容                                                                                                                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 上部       | アプリ名、店名・住所の検索欄（右端に結果件数）、「＋ 店舗を追加」、地域の移動、地図スタイル                                                                                                                                     |
| 左         | 「店舗を探す」（検索条件・結果一覧）／「地図の表示」（表示モード、3D建物、駅、視点操作）／「比較・集計」（市区町村別・駅周辺の集計、調査済みエリア）／「記録」（訪問履歴・お気に入り等）／「はしご酒」（ルート計画）の5つのタブ |
| 中央       | 3D地図                                                                                                                                                                                                                          |
| 右         | 選んだ店舗の詳細、または追加・編集フォーム（✕で閉じると地図が広がります）                                                                                                                                                       |
| 地図の右下 | 表示モードの凡例と、対象件数・データの限界の注意書き                                                                                                                                                                            |
| 下部       | 地図の状態（中心座標・ズーム・傾き・方位）と地図の出典                                                                                                                                                                          |

## 地図のマーカー

- 丸の中の一文字が料理ジャンルです。

  | 文字 | ジャンル         |
  | ---- | ---------------- |
  | 焼   | 焼きとん・焼き鳥 |
  | 煮   | 煮込み           |
  | お   | おでん           |
  | 魚   | 刺身・海鮮       |
  | 酒   | 日本酒           |
  | 麦   | ビール・ホッピー |
  | 角   | 角打ち           |
  | 他   | その他・未分類   |

- 複数のジャンルを持つ店舗は、最初に登録したジャンルで表示されます（全ジャンルは詳細パネルで確認できます）。
- オレンジの大きな丸は近くにある複数店舗のまとまりです。クリックすると拡大します。ズーム15程度まで寄ると個別に表示されます。
- 半透明のマーカーは「閉店の可能性あり」「閉店確認済み」の店舗です。
- 選択中の店舗は白い輪で囲まれます。
- 地図上の店舗は、現在の検索条件に合う店舗だけが表示されます。

## 店舗を探す

1. 上部の検索欄に店名や住所の一部を入力します（全角・半角、空白の違いは無視されます）。
2. 左パネルの「絞り込み条件」を開き、条件を選びます。条件はすべて同時に適用されます（AND）。同じ項目内で複数選んだ場合は、いずれかに当てはまる店舗が対象です。
3. 適用中の条件は件数の下にボタンで表示されます。押すとその条件だけ解除されます。

| 条件           | 注意                                                                                                                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 立ち呑み形式   | 形式が「未確認」の店舗は、形式を指定すると結果に含まれません                                                                                                                             |
| 営業日時       | 登録された営業時間（日本時間）で判定します。営業時間が未確認の店舗は、「営業時間が未確認の店舗も含める」を選ばない限り含まれません。臨時休業・祝日は反映されません                       |
| 駅を起点に探す | 駅を選ぶと、その駅を最寄り駅として登録した店舗と、駅から指定距離（300/500/800m、直線距離）以内の店舗が対象になります。駅は駅名で候補を絞り込めます。同じ名前の駅は路線で区別してください |

## 密度・分布を見る（表示モード）

左パネル「地図の表示」→「表示モード」で切り替えます。どのモードも**現在の検索条件に合う店舗**だけを対象にします。

| モード               | 内容                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------- |
| 店舗マーカー         | 店舗を1件ずつ表示（通常の表示）                                                             |
| 密度（ヒートマップ） | 登録店舗が集まっている場所ほど明るい色。濃さの基準は固定で、件数の少ない地域を強調しません  |
| 密度（3D柱）         | 250m・500m・1km四方のマスごとの店舗数を、柱の高さと色で表示。マスをクリックすると件数を表示 |
| ジャンル別の分布     | 代表ジャンル（最初に登録したジャンル）で色分けした点。点をクリックすると店舗詳細を表示      |
| 予算帯別の分布       | 予算帯で色分けした点。「未確認」は灰色                                                      |

「訪問済み店舗の分布」は、訪問記録の機能（今後追加）の実装後に使えるようになります。

### 「店が少ない」と「データがない」の区別

- 登録店舗は網羅的な調査に基づくものではありません。店舗が表示されない場所は「データがない（未調査）」であり、「店が少ない」とは限りません。
- 自分で一通り調べた範囲は **調査済みエリア** として登録できます（下記）。3D柱の表示では、調査済みエリア内で店舗が0件のマスを緑色の「調査済み・0件」として表示し、色のない「データなし」と区別します。
- ヒートマップ・3D柱の表示では、調査済みエリアを緑の破線で示します。

## 比較・集計

左パネル「比較・集計」タブ。数値は登録済みの店舗の件数で、検索条件を反映します。

- **市区町村別**：件数、確認済みの件数、主なジャンル。
- **駅周辺の店舗数**：駅から直線距離300/500/800m以内の店舗数の多い順（上位15駅）。駅名を押すと「店舗を探す」タブに移り、その駅を起点に絞り込んで駅へ移動します。
- **調査済みエリア**：「＋ 調査済みエリアを追加」から、エリア名・中心（駅を選ぶか、地図をクリック）・半径（50〜3000m）・調査日を入力して保存します。一覧のエリア名を押すとそこへ移動します。不要になったら「削除」（店舗データは消えません）。

## 駅

- 駅データは国土数値情報（国土交通省）の鉄道データから作成した、東京都・埼玉県の884駅です（島しょ部を除く）。
- 「地図の表示」→「駅」で地図に表示できます（ズーム12以上。ズーム13以上で駅名も表示）。
- 店舗詳細には「近くの駅」（直線距離、2km以内の近い順に3駅）を参考として表示します。
- 店舗の追加・編集では、入力した位置から近い駅を最寄り駅の候補として表示します。最寄り駅かどうかはご自身で判断して選んでください。

## 店舗の詳細

- 分からない情報は「未確認」と表示されます。アプリが推測で補うことはありません。
- 「確認状況」が「未確認」の店舗には注意書きが表示されます。
- 価格例は品目ごとに確認日・出典を表示します。税・お通し・チャージが含まれない場合があります。
- 営業時間の下に、登録内容に基づく現在の営業状況（参考）を表示します。判定できない場合は「判定できません」と表示します。
- 公式サイトや出典のリンクは、リンク先のドメインを表示し、新しいタブで開きます。

## 店舗を追加・編集する

1. 上部「＋ 店舗を追加」、または詳細パネルの「編集」を押します。
2. **必須は店名・緯度・経度のみ**です。分からない項目は空欄や「未確認」のままにしてください。
3. 位置は次のどちらかで入力します。
   - 緯度・経度を直接入力（例：緯度 35.6812、経度 139.7671）
   - 「地図をクリックして位置を選択」を押し、地図上をクリック
     入力した位置には地図上に白いピンが表示されます。
4. 緯度と経度が逆の場合や、東京都・埼玉県の範囲外の場合は警告が表示されます。
5. 営業時間は曜日ごとに「未確認／営業／定休日」を選びます。深夜営業は閉店時刻を開店時刻より前（例：17:00〜02:00）にすると翌日にまたがる扱いになります。
6. 出典は「新しい出典を追加」から登録し、チェックを付けてその店舗に紐づけます。
7. 「確認済み」にするには、出典1件以上と最終確認日が必要です。
8. 同じ名前の店舗が150m以内にある場合は重複の可能性を表示します。別の店舗であれば「別の店舗として登録する」にチェックしてから保存します。

## 店舗を削除する

詳細パネルの「削除」を押し、確認画面で「削除する」を押します。取り消しはできません。
初期データの店舗を削除した場合は、削除した記録が保存され、次回以降も表示されません。

## 自分の記録（お気に入り・訪問記録）

店舗の詳細パネルの「自分の記録」欄で記録します。店舗の情報（事実）とは分けて保存され、店舗データ自体は変わりません。

- **お気に入り／行きたい店／再訪したい**：ボタンを押すと登録、もう一度押すと解除します。3つは別々に登録できます。
- **訪問記録**：「＋ 訪問記録を追加」から、訪問日時（必須）、支払った金額、評価（★1〜5、未評価も可）、注文した品（1行に1品）、雰囲気のタグ、感想・メモ、写真の参照先を記録します。日時以外はすべて任意です。
  - 写真は、ファイル名や保存場所をメモとして残すだけです。画像そのものは保存・アップロードされません。
  - 記録の「編集」「削除」は、記録ごとのボタンから行います。
- 記録には、記録した時点の店名も保存されます。店舗を削除したり名前を変えたりしても、過去の記録がどの店のものか分かります。

### 店舗を削除するときの訪問記録

訪問記録のある店舗を削除する場合は、確認画面で「訪問記録を残す」か「訪問記録も削除する」を選べます。残した記録は「記録」タブに記録時の店名で表示されます。お気に入り等の登録は店舗と一緒に削除されます。

## 記録タブ（訪問履歴）

左パネル「記録」タブ。

- これまでの訪問回数、訪れた店の数、支払い合計（金額を記録した回のみ）、平均評価（評価を付けた回のみ）を表示します。
- 「訪問履歴」は月ごとに新しい順で並びます。店名を押すとその店舗へ移動します。
- 「お気に入り」「行きたい店」「再訪したい」で、登録した店舗の一覧を表示します。

## 自分の記録で探す・地図で見る

- 「店舗を探す」→「絞り込み条件」→「自分の記録」で、訪問済み／未訪問、お気に入り・行きたい店・再訪したい（いずれかに当てはまる）で絞り込めます。
- 「地図の表示」→「表示モード」→「訪問済み店舗の分布」で、訪問済みの店を明るい色、未訪問の店を灰色で表示します。

## データの保存とバックアップ

画面で追加・編集したデータはブラウザ内（IndexedDB）に保存され、ページを再読み込みしても残ります。
ただし、ブラウザの閲覧データを削除すると失われ、別のPCやブラウザとも共有されません。画面上部の「データ管理」から定期的にバックアップしてください。

| 書き出しの種類         | 内容                                                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 全データのバックアップ | ブラウザ内に保存しているすべて（追加・編集した店舗、出典、削除記録、訪問記録、お気に入り等、調査済みエリア）。**復元にはこれを使います** |
| 個人記録               | 訪問記録・お気に入り等・調査済みエリアのみ                                                                                               |
| 店舗データ             | 画面に表示しているすべての店舗（初期データを含む）と出典                                                                                 |

- 書き出したファイルはブラウザのダウンロードフォルダに保存されます（例：`tachinomi-atlas-backup-202610291230.json`）。
- 「最終バックアップ」日時を表示し、まだ無い場合や30日以上たっている場合は書き出しをおすすめします。
- 書き出したファイルには個人的なメモが含まれます。共有する場合は注意してください。

### 復元（読み込み）

1. 「データ管理」→「読み込み（復元）」で JSON ファイルを選びます。
2. 内容が検証され、読み込む件数と注意点が表示されます（この時点ではデータは変わりません）。形式が違う・値が不正・IDが重複しているファイルは読み込めません。
3. 店舗が見つからない訪問記録などがある場合は、それも読み込むか選べます。
4. 読み込み方を選びます。
   - **統合する**：同じIDのデータはファイルの内容で上書きし、それ以外は残します。
   - **置き換える**：今ブラウザにある自分のデータをすべて削除してから読み込みます。
5. 「読み込む…」→ 確認して実行します。途中で失敗した場合、データは変更されません。

## はしご酒プランナー

左パネル「はしご酒」タブで、複数の店を回る計画を作ります。変更は自動で保存されます。

### 作り方

1. 店舗の詳細パネルで「＋ はしご酒に追加」を押します。ルートが無い場合は新しいルートが作られます（追加先は「はしご酒」タブで選んでいるルートです）。
2. 「はしご酒」タブで、ルート名・予定日・開始時刻・出発駅（任意）・予算・想定所要時間・メモを入力します。
3. 各店舗の「↑ 前へ」「↓ 後ろへ」で順番を入れ替え、「外す」でルートから外します（1ルート20軒まで）。
4. 各店舗の「滞在」で滞在時間（分）を、「頼む予定の品」で登録された価格例から頼む品を選べます。
5. 「地図でルート全体を表示」で、訪問順の番号と線を地図に表示します。

### 距離・時間の見方

| 表示                              | 意味                                                                                                       |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 直線 ○m・徒歩の目安 約○分（概算） | 2地点を直線で結んだ距離と、それを分速80mで割った目安。実際の道のり・所要時間より短くなります。地図では点線 |
| 徒歩 ○m・約○分（経路検索）        | openrouteservice で取得した徒歩経路の道のりと所要時間。地図では実線                                        |

- 予定日と開始時刻を入れると、各店の到着〜出発時刻を計算し、登録された営業時間と照合します。
  - 「営業時間内（登録情報）」：到着から出発まで、登録された営業時間内です。
  - 「営業時間外を含む」：到着・出発のどちらかが登録された営業時間外です。
  - 「営業時間を判定できません」：その曜日の営業時間が未確認などで判定できません。営業しているとは限りません。
- 臨時休業・祝日・最新の変更、終電は考慮しません。
- 「予定の品の合計」は、選んだ品の登録価格の合計です。お通し・チャージ・税・サービス料は含みません。予算・想定所要時間を入れると、差を表示します。

### 徒歩ルートを取得する（任意）

既定では外部とは通信せず、直線距離と概算だけを表示します。実際の徒歩経路を使いたい場合：

1. [openrouteservice](https://openrouteservice.org/) で無料登録し、API キーを発行します（無料プランは1日2,000回まで）。
2. 「はしご酒」タブ →「徒歩ルートの設定」で「openrouteservice で徒歩ルートを取得する」を選び、API キーを入力して「設定を保存」を押します。
3. 「徒歩ルートを取得」を押します。押したときだけ、ルート上の店舗・駅の座標が openrouteservice に送信されます（個人記録は送信しません）。

- 店の順番を変えると、取得済みの経路は使わず直線・概算の表示に戻ります。もう一度「徒歩ルートを取得」を押してください。
- API キーはこのブラウザ内にだけ保存され、バックアップには含まれません。
- 失敗した場合は原因（キーの誤り、回数の上限、接続できない など）が表示されます。自動で再試行はしません。

## 予算内で飲める店を探す

「店舗を探す」→「絞り込み条件」→「予算内で飲める店（注文モデル）」で、1,000／2,000／3,000円以内、または任意の予算を選びます。

- 登録された価格例を安い順に2品（または3品）選んだ合計が予算内の店舗を表示します。
- 価格例が足りない店舗は、予算内と断定できないため結果に含まれません。
- お通し・チャージ・税・サービス料は含みません。

## うまく動かないとき

| 症状                                     | 対処                                                                                                           |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 地図が表示されない                       | 画面上部に原因と対処が表示されます。インターネット接続を確認し「再読み込み」を押してください                   |
| 「保存済みデータを読み込めませんでした」 | プライベートウィンドウでは保存できない場合があります。通常のウィンドウで開いてください                         |
| 「店舗データを保存できませんでした」     | ブラウザの空き容量や設定を確認してください。入力内容はフォームに残っています                                   |
| 「店舗データに確認が必要な点があります」 | 初期データ（JSON）に不正な値や存在しない出典・駅の参照があります。一覧の内容を確認して JSON を修正してください |
